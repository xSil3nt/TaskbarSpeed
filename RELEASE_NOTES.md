Show and hide animations run at 500% speed. The wait before hiding runs at 250% speed (normally 500 ms to 200 ms).

Download **TaskbarSpeed-win11-24H2-x64.zip**, extract it, and run **Setup.cmd**. Turn on taskbar auto-hide in Windows first.

This build requires matching x64 Windows 11 24H2 taskbar files from build 26100.9550. Different files are rejected. No Windhawk or compiler is required.

Run **Undo.cmd** to disable and remove startup.
